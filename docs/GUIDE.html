Content OS 사용 가이드

레퍼런스 하나를 증거가 붙은 발행 후보로 바꾸는 데까지, 처음부터 끝까지.

규칙은 하나입니다. 증거 없는 글은 발행되지 않습니다. 실제 자료를 붙이지 않으면 게이트가 열리지 않습니다. 체크박스를 다 켜도 안 열립니다.
1 수집레퍼런스 담기
2 채점쓸 만한지 판정
3 제작초안 + 증명
4 발행상태 관리
0

설치하고 실행하기

5분

다운로드한 폴더에서 터미널을 열고 두 줄을 칩니다.

npm install
npm run dev

브라우저에서 http://localhost:3000을 엽니다. 끝입니다.

가입도, 데이터베이스도, API 키도 필요 없습니다. 처음 열면 연습용 데모 데이터가 들어 있습니다. 마음껏 눌러보세요. 데이터는 이 브라우저에만 저장됩니다.

터미널을 켜 둔 채로 쓰세요. 창을 닫으면 앱도 멈춥니다. 다시 쓰려면 npm run dev만 다시 치면 됩니다.

1

레퍼런스 담기

2분

왼쪽 수집 → + 소스 추가를 누릅니다. 세 칸만 채우면 됩니다.

소스 라이브러리 — 새 소스 기록
제목고객은 도구가 아니라 해결된 결과를 산다
유형Customer call
Raw Notes통화에서 반복된 말을 그대로 붙여넣기
URL비워도 됩니다
URL을 넣어도 내용이 자동으로 가져와지지 않습니다. 핵심 문장과 본인이 관찰한 것을 Raw Notes에 직접 붙여넣으세요. 여기가 부실하면 이후 단계가 전부 부실해집니다.

저장하면 Inbox 상태로 2단계에 나타납니다.

2

채점하고 승급시키기

3분

왼쪽 채점 · 승급으로 갑니다. AI 채점 요청을 누르면 30점 만점으로 점수와 이유가 나옵니다.

보이는 것뜻
총점 / 30이 소스로 글을 쓸 가치가 있는가
증명 / 15내가 증거를 댈 수 있는 이야기인가
권위 / 15내가 직접 겪어서 말할 수 있는가

AI 점수는 추천일 뿐입니다. 읽고 적용하거나 무시하세요. 적용한 뒤에도 직접 고칠 수 있습니다.

쓸 만하다고 판단되면 제작으로 승급을 누릅니다.

AI 키가 없어도 됩니다. 채점을 직접 입력하고 승급시키면 그대로 진행됩니다. AI는 도우미지 관문이 아닙니다.
3

초안 쓰고 증명 붙이기

5분

이 단계가 이 앱의 전부입니다. 나머지는 여기로 오기 위한 준비입니다.

  1. 왼쪽 제작 → 채널(LinkedIn, Instagram …)을 고릅니다
  2. AI 초안 생성을 누릅니다. Hook, 본문, CTA가 채워집니다 — 전부 직접 고칠 수 있습니다
  3. 아래 필요한 증명 칸에서 + 새 증명 등록을 누릅니다
제작 — 증명 첨부
제목3주간 문의 응답 시간 로그
유형before/after metric
이 자료가 보여주는 것평균 응답이 6시간에서 40분으로 줄어든 기록
파일 경로 또는 링크선택
"이 자료가 보여주는 것"을 대충 쓰지 마세요. 여기가 비면 증명이 아니라 주장입니다. 한두 문장이면 충분하지만 구체적이어야 합니다.

등록하면 배지가 바뀌고 게이트가 열립니다.

상태게이트발행
증명 없음Needs proof안 됨
증명 있음Ready for review가능

이미 등록한 증명은 다른 초안에도 다시 붙일 수 있습니다. 워크플로우 맵 하나로 LinkedIn 글과 Threads 글을 같이 받칠 수 있습니다.

체크박스를 다 켜도 게이트는 열리지 않습니다. 오른쪽 Brand Voice Gate 5개 항목은 글의 품질을 스스로 점검하는 용도입니다. 발행 여부를 가르는 것은 실제로 붙은 자료입니다.

증명을 잘못 붙였다면 떼어내기를 누르세요. 게이트가 다시 닫힙니다.

4

발행 상태 관리하기

1분

리뷰 파이프라인으로 이동을 누르면 4단계로 넘어갑니다. 여기서 상태만 옮기면 됩니다.

Draft → Review → Scheduled → Published

이 앱은 대신 발행해주지 않습니다. 글은 각 플랫폼에 직접 올리고, 여기서는 무엇이 어디까지 갔는지만 관리합니다.

증명이 없는 초안은 목록에서 BLOCKED로 표시됩니다. 대시보드에서도 바로 보입니다.

첫 콘텐츠 완주 체크리스트

  • 소스 1개를 Raw Notes까지 채워서 저장했다
  • 채점하고 제작으로 승급시켰다
  • 채널 1개의 초안을 만들고 내 말로 고쳤다
  • 실제 자료를 등록하고 증명 있음으로 바꿨다
  • 게이트가 Ready for review가 됐다

다섯 개를 다 채우면 이 앱을 쓸 줄 아는 것입니다. 약 15분 걸립니다.

막히면

증상원인과 해결
브라우저에 아무것도 안 뜬다터미널이 꺼졌습니다. npm run dev를 다시 치세요.
AI 채점·초안이 실패한다API 키가 없거나 잘못됐습니다. 템플릿 초안이 대신 만들어지니 직접 고쳐 쓰면 됩니다.
게이트가 안 열린다증명을 붙이지 않았습니다. 3단계의 + 새 증명 등록을 누르세요.
데이터가 사라졌다브라우저 저장소를 지우면 같이 지워집니다. 여러 기기에서 쓰려면 README의 Supabase 설정을 보세요.
제목 글꼴이 달라 보인다정상입니다. Gmarket Sans가 없으면 Pretendard로 표시됩니다.

선택 설정

  • AI 켜기 — Google AI Studio에서 무료 키를 받아 .env.local에 GEMINI_API_KEY로 넣습니다
  • 여러 기기에서 쓰기 — 본인 Supabase 프로젝트를 연결합니다. README 참조

둘 다 안 해도 앱은 완전히 동작합니다.
