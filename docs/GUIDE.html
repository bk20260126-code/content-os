Content OS 사용 가이드

내 소재로 글을 쓰고, 근거를 확인하고, 발행 기록을 남기는 순서입니다.

근거와 내용을 직접 확인한 글만 발행 완료로 기록합니다.자료 등록, 근거 확인, 최종 검토는 서로 다른 단계입니다. 실제 게시는 각 채널에서 직접 합니다.
0

설치하고 실행하기

Node.js와 npm을 설치합니다. Git이 있다면 아래 순서로 실행하세요.

git clone https://github.com/bk20260126-code/content-os.git
cd content-os
npm ci
npm run dev

ZIP으로 받았다면 압축을 풀고 package.json이 있는 폴더에서 마지막 두 줄을 실행합니다. 브라우저에서 http://localhost:3000을 열고 터미널은 켜 두세요.

직접 작성에는 계정·DB·AI 키가 필요 없습니다.개발 모드 첫 실행에는 연습용 소스가 보입니다. 클라우드와 프로덕션 모드에는 데모를 자동으로 넣지 않습니다.
1

내 글의 방향과 소재 정리

설정 · 백업에서 독자·목적·말투를 적습니다. 설정은 AI 생성·채점·평가에 함께 적용됩니다. 직접 작성이라면 생략해도 됩니다.

수집 → + 소스 추가를 누르고 제목·메모를 적습니다. 저장 후 다음을 짧게 정리하세요.

  • 이 자료에서 말할 수 있는 핵심 주장
  • 출처·작성자와 원문 날짜 또는 관찰일
  • 직접 인용한 문장이나 관찰한 사실
  • 아직 확인하지 못한 조건·표본·한계
URL의 내용을 자동으로 가져오지 않습니다.필요한 문장과 관찰을 직접 적어 주세요. 날짜를 모르겠다면 모른다고 남깁니다.

이 소재로 직접 작성을 누릅니다. 여러 소재의 가치를 비교하려면 채점 · 승급을 선택해서 사용하세요.

2

직접 작성하거나 AI 도움 받기

  1. 소스와 채널을 고르고 직접 작성을 누릅니다.
  2. 도입부·본문·독자의 다음 행동을 내 말로 씁니다.
  3. 근거로 뒷받침할 핵심 주장에 자료로 확인할 주장 한 가지를 적습니다.

AI로 초안 만들기는 선택 기능입니다. Gemini 키가 없거나 요청이 실패해도 직접 작성을 시작할 수 있습니다. AI가 제시한 사실은 원문과 대조하세요.

3

자료 연결과 사람의 검토

  1. + 새 증명 등록에서 제목·유형·자료가 보여주는 사실·선택적 원문 링크나 보관 위치를 적고 등록하고 첨부합니다.
  2. 자료 원문을 직접 열어 핵심 주장을 뒷받침하는지 확인합니다. 로컬 파일 경로는 브라우저에서 자동으로 열리지 않으므로 직접 찾아 여세요.
  3. 자료 아래의 원문을 직접 확인했습니다 항목을 표시합니다.
  4. 오른쪽 필수 조건인 작성자 경험·구체성·상투성 점검을 완료합니다.
  5. 내용·근거 최종 확인하고 리뷰로 이동을 누릅니다.
‘자료 등록됨’만으로 검토를 통과하지 않습니다.필수 조건과 근거 확인이 모두 필요합니다. 문제·해결 구조, 고유 관점, 다음 행동은 개선 권고이며 통과 조건에는 포함되지 않습니다.

AI 평가는 체크 항목의 추천입니다. 원문 확인이나 최종 검토를 대신하지 않습니다. 본문·주장·자료를 변경하면 근거 확인과 최종 검토를 다시 진행합니다.

4

실제로 게시하고 기록 남기기

각 플랫폼에서 직접 게시한 뒤 발행 관리 → 실제 발행 기록하기를 누릅니다. 게시물 링크를 입력하고 실제 게시 확인을 표시한 다음 발행 완료로 기록합니다.

검토가 끝난 글은 발행 예정으로 옮길 수 있습니다. 날짜 예약이나 자동 게시 기능은 제공하지 않습니다.

발행 기록에는 당시 내용과 링크·기록 시각이 남습니다. 수정하려면 발행 당시 내용·수정본 보기 → 수정본 만들기를 누르세요. 원래 발행 내용은 보존됩니다.

다음 글에 반영할 교훈에는 유지할 점이나 바꿀 점을 한 줄 남기세요.

5

백업과 복원

상단 저장 상태를 확인하세요. 기본 사용은 이 브라우저에만 저장됩니다. 브라우저 데이터를 지우기 전에 설정 · 백업 → 전체 백업 내려받기를 누릅니다.

복원할 파일을 고르면 형식을 검증하고 항목 수를 미리 보여줍니다. 현재 사본 백업하기 후 이 백업으로 복원을 누르면 작업 전체를 교체합니다.

백업에는 근거 설명과 링크가 들어갑니다.링크가 가리키는 이미지·문서 파일 자체는 별도로 보관하세요. 손상되거나 지원하지 않는 데이터는 자동으로 덮어쓰지 않습니다.

클라우드 모드의 저장 대기·충돌은 클라우드 사본 비교에서 양쪽 사본을 내려받아 확인한 후 유지할 사본을 선택합니다. 자동 병합하지 않습니다. 다른 탭의 변경 때문에 저장이 멈췄다면 현재 작업을 백업한 뒤 새로고침하세요.
